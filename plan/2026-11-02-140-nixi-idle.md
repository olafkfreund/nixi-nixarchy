# Plan: Nixi shrinks when idle and pops up when something happens

## Approved decisions (from the spec; this plan does not need it)

- **Repo:** `olafkfreund/nixoarchy-snowflake`. One PR. **Start only after
  #138 PR B (`feat/138-props`) is merged.** Worktree:
  `git -C /mnt/code/Source-home/GitHub/nixoarchy-snowflake worktree add ../snowflake-140 -b feat/140-nixi-idle origin/main`.
  Line numbers below are from `main` at `51ad40a`; PR B moves `index.html`.
  Re-find every anchor by the name or text given, never by the number alone.
- **Setting `idle_mode`:** `"off" | "shrink" | "doze"`, default
  `"shrink"`. `doze` shrinks first, then hides while staying awake.
- **Constants** (in the page, not settings):
  - `IDLE_SHRINK=45000` and `IDLE_DOZE=300000` (ms);
  - holds: `12000` normally, `20000` for a "needs you", and `15000` after
    your own turn ends;
  - the idle check runs every 500 ms.
- **The peek:** `#stage` scaled to `.4` and pushed toward the screen corner
  nearest to him. The window is **never resized**.
- **Doze** hides the window **without** `nixiHidden()` / `/api/sleep`, so the
  wake word, the notification takeover and events keep working. Popping up
  is quiet (`doze:show`: no `present()`, no `grab_focus()`), except for your
  own actions and approval/password prompts, which use the existing
  `show()`.
- **Deliberate hide** (`hiddenNow`) is unchanged and stays fully off.
- **Not idle while:**
  - `busy`, `playing`, `rec`, `transcribing` or `follow`;
  - `menuOn`, `pendingAppr`, a password card, `ask`/`setEl`/`panelEl`
    open, `capOn`, `notifyRow`, or the chip with `act`;
  - `AM`, or `attnPend` while under 60 s old;
  - `body.hover` or `body.bar`, `dragged` or `downAt`, or `hiddenNow`.
- **Restore table:**

| Event | Hold | From doze |
|---|---|---|
| `wake`, `nixiCmd`, a click or 300 ms hover on him | 15 s after the turn | `show()` (focus) |
| `approve`, `askpass` | until answered, then 12 s | `show()` (focus) |
| `attention`, `kind!=='done'` | 20 s | `doze:show` |
| `remind`; `ambient` with `ev.alert` | 12 s | `doze:show` |
| `notify` shown by `notifyDrain`; `attention` `done`; `nudge` | 11 s | `doze:show`; but in `SIT.fullscreen` or `SIT.meeting`, no restore at all |
| other `ambient`, `situation`, weather, looks | — | none |

## Repo traps (every step)

- `index.html` repaints every frame. New work runs on the 500 ms idle check,
  not per frame. No SVG `filter`s.
- `#face` gets no transform (the notch reuses it).
- `sendRegion()` decides which pixels take clicks. A stale region blocks
  clicks near him: resend it on every state change and on `transitionend`.
- `show()` in `window.py` takes focus. Only your own actions and prompts may
  use it. Every automatic pop-up uses `doze:show`.
- Hooks, the notification takeover and the wake word depend on `Wake.asleep`
  staying `False` while dozing: never post `/api/sleep` for doze.
- `Spring.x` is the value, `.v` the velocity.
- Tests: `python3 -m unittest discover -s tests -q` (pytest isn't
  installed). `tests/test_no_herdr_writes.py` must stay green.

3. **`app/static/index.html`: the peek** → verify with step 5's checks.
   - **CSS**, next to `body.hover #stage{…}` (`:26`):
     - `body.peek #stage{transform:translate(var(--px,102px),var(--py,99px)) scale(.4)}`;
     - in `body.peek`, the orbs, rays and halo (`#orbBack,#orbFront,#raysW,#haloW`)

     - `#agentMark` stays visible.
   - **`window.nixiCorner=c=>{…}`** sets `--px`/`--py` on `body`:
     `br` → `102px,99px`; `bl` → `-102px,99px`; `tr` → `102px,-99px`;
     `tl` → `-102px,-99px`.
   - **State:** `let idleSt='full', idleHoldUntil=0, dozing=false, IDLE_K=1`.
     Expose `window.nixiIdleScale=k=>{IDLE_K=k}`, a test hook that multiplies
     the timers.
   - **`idleBusy()`:** returns `true` for any "not idle while" condition
     above.
   - **`idleCheck()`** runs from `setInterval(…,500)`:
     - with `info.idle_mode==='off'`, or `idleBusy()`, it does
       `setIdle('full')` and returns;
     - otherwise
       `t=now-Math.max(lastActive,lastMouse,idleHoldUntil)`, then
       `setIdle(info.idle_mode==='doze'&&t>=IDLE_DOZE*IDLE_K?'doze':t>=IDLE_SHRINK*IDLE_K?'peek':idleSt==='doze'?'doze':idleSt)`.
       Only move forward: full → peek → doze; going back happens only
       through `restore`.
   - **`setIdle(s)`:**
     - if nothing changes, return;
     - toggle `body.peek` on for `peek` and `doze`;
     - entering `doze`: `dozing=true; native('doze:hide')`;
     - leaving `doze`: `dozing=false`;
     - then `sendRegion(true)`.
   - **`restore(hold, focus)`:**
     - `idleHoldUntil=max(idleHoldUntil, now+hold)`;
     - if dozing: `native(focus ? 'show' : 'doze:show')`, then `entrance()`;
     - then `setIdle('full')`.
   - **`sendRegion()`** (`:2617`): treat `body.peek` like `inBar`. The
     click-through check becomes
     `if(!info.click_through&&!inBar&&!inPeek)`, and the peek adds
     `add(E.body,8)`.
   - Add `$('#stage').addEventListener('transitionend',()=>sendRegion(true))`.
   - **Peek clicks:** on `E.body` `pointerdown`, when `body.peek` is set,
     call `restore(12000)`, `stopPropagation()` and `preventDefault()` (no
     menu). On `mouseenter`, start a 300 ms timer that calls
     `restore(12000)`; `mouseleave` clears it.
   - **CPU while dozing:** at the end of `frame()`, if `dozing`, skip
     `requestAnimationFrame(frame)` and set `framePaused=true`. `restore()`
     restarts it with `if(framePaused){framePaused=false; requestAnimationFrame(frame);}`.

   Traps:
   - `lastActive` is also bumped by `wake()` from moods. That's fine; it
     only makes him idle later.
   - Don't call `nixiHidden`/`nixiShown` from here.
