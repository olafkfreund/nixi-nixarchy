# Plan: Drop the `@ff-labs/fff-node` native index from `@` file search

## Approved decisions, carried over

- `@` file search is answered by plocate and `fd` alone. **Typo-tolerant fuzzy
  search is deliberately lost** -- measured: `confguration` 48 rows -> 0,
  `pakcage` 70 rows -> 0. Substring, extension and multi-term `fd` matching are
  unaffected; latency stays 135-568 ms on a 3.1M-file `$HOME`.
- The measured ordering regression **is fixed here**, not accepted: plocate's
  `--limit 300` is exhausted in `.agents/` and `.claude/` before reaching
  `Documents/`, so the priority roots get their own plocate patterns. Sorting
  the 300 results was tried and does not work.
- `bridge/files.js` gets an `isMain` guard and two exports so it can be tested
  at all. `locatedUnderBase()` is a security boundary and gets direct tests.
- `nix/package.nix` loses `autoPatchelfHook`, `stdenv.cc.cc.lib` and the
  `binaryExists()` installCheck. No other installCheck assertion names a file
  this change deletes.
- No new runtime dependency. `fd` and `plocate` are already required.

## Steps

1. `bridge/files.js`: delete the `@ff-labs/fff-node` import, `created`,
   `finder`, `ready`, `initialize()` and its call, `usefulFuzzyMatch()`,
   `strictFileMatch()`, the indexed half of `search()` and `finder?.destroy()`.
   `search()` short-circuits on a <2-character query, then calls
   `fallbackFiles()` and `emitProgressively()`.
   -> verify by `node --check bridge/files.js` and
   `! grep -n 'fff\|finder\|focused' bridge/files.js`.

2. `bridge/files.js`: in `fallbackFiles()`, replace the single plocate call with
   a `locate(patterns)` helper; run one call per entry of `priorityFileRoots`
   (pattern `${root}/` plus the query) concurrently with the unrestricted call;
   concatenate priority output first, then unrestricted, and de-duplicate.
   `complete` keeps reading the unrestricted output's line count against 300.
   -> verify by the end-to-end test in step 5 and by re-running the intent's
   harness (step 9).

3. `bridge/files.js`: extract the `fd` pattern expression into
   `filePattern(query)`; add `const isMain = process.argv[1] ===
   fileURLToPath(import.meta.url)` and run `discoverRepos()` and the readline
   loop only when `isMain`; `export { locatedUnderBase, filePattern }`.
   -> verify by `node -e "await import('./bridge/files.js')"` returning
   promptly without scanning, and by the tests importing the module.

4. `bridge/package.json` + `package-lock.json`: `npm uninstall @ff-labs/fff-node`.
   -> verify by `! grep -q ff-labs bridge/package.json bridge/package-lock.json`.

5. New `bridge/files.test.js`: `locatedUnderBase()` cases (inside `$HOME`,
   outside, `node_modules/`, `.cache/`, missing path, directory-vs-file, and
   the `/tmp/home-evil` prefix-confusion case); `filePattern()` cases
   (metacharacters stripped, terms joined with `.*`, all-punctuation -> empty);
   one subprocess test that spawns `files.js` with a temporary `HOME` and stub
   `plocate`/`fd` on `PATH` and asserts row shape, priority-root ordering and
   that a stale out-of-`HOME` plocate hit is dropped.
   -> verify by `node --test bridge/*.test.js`.

6. Prove each new test fails when its subject is broken: invert
   `locatedUnderBase`'s prefix check, the `node_modules`/`.cache` exclusion, the
   `isDirectory` branch, `filePattern`'s sanitiser, and the priority ordering,
   one at a time; record the failure message; revert.
   -> verify by pasting the recorded messages into the PR.

7. `nix/package.nix`: drop the `autoPatchelfHook` and `stdenv` arguments, the
   `nativeBuildInputs`/`buildInputs` lines in `bridgeModules` and their comment,
   and the `binaryExists()` installCheck block. Re-read the remaining
   installCheck file list and confirm nothing names a deleted file.
   -> verify by `! grep -n 'autoPatchelf\|cc\.lib\|ff-labs' nix/package.nix`.

8. `nix/package.nix`: regenerate `npmDepsHash` from the failing build's
   `got:` line.
   -> verify by `nix build .#nixi` succeeding.

9. Re-run the intent's harness against the final `bridge/files.js` and record
   the new timings and top rows.
   -> verify by the `hypr` and `.png` queries no longer leading with
   `.claude/` / `.agents/` paths.

the indexed code path return together; the new tests go with them, since they
test code the revert also removes. Nothing outside this branch depends on the
change.
