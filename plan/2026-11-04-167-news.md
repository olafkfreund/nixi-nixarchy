# Plan: News gets its own popout and animation

## Approved decisions (from the spec, so this file stands alone)

- **Code:** `olafkfreund/nixoarchy-snowflake`, branch `feat/167-news` from
  `main` **after #166 is merged** (so `say` and the kind list exist), worktree
  `../nixoarchy-snowflake-167`. Artifacts in nixi-nixarchy. If #166 hasn't
  landed when this starts, branch from `main` and do step 1.
- **`say`:** shared with #166 word for word: every plugin kind may carry
  `say` (≤ 200 chars); `Store.put()` pops it from the page copy only;
  `plugin_stage()` returns `st.get("say") or "Here you go."`, spoken and shown
  as his caption, never in a prompt or Nixi's log; the agent path ignores it.
- **`headlines` kind:** `{v, kind, title ≤ 80, say? ≤ 200, source? ≤ 120,
  items[1–5]}`; item `{title ≤ 160, source ≤ 40, at, url?}`; `at` is
  `type(at) is int and at > 0`, or `null`; more than 10 minutes in the future
  → `null`; a URL failing `news_url_ok` is dropped (the story stays, without
  Open); unknown keys dropped; anything else wrong → `None`.
- **`news_url_ok(u)`:** a string ≤ 400 chars with no whitespace or control
  characters; scheme `https`; no `:` or `@` in the netloc (no port, user info
  or IPv6 literal); host = `hostname.lower().rstrip(".")`; labels
  `[a-z0-9-]{1,63}`, no empty label, at least two labels, the last
  `[a-z]{2,63}` (refuses every numeric, octal and hex IPv4 form); not
  `localhost`, and not ending in `.localhost`, `.local`, `.lan`, `.home`,
  `.internal`, `.home.arpa`, `.ts.net`. No DNS check: the browser opens the
  link (`xdg-open`), and redirects or names pointing inward are the browser's
  to handle; the spec says so.
- **Tokens:** each item with a URL → `open` = `("link", {"url"})`; the page
  item has no `url`. One list-wide copy token under `page["copy"]` =
  `("facts", {"text": titles and sources})` (the payload `stage_act` copy
  reads).
- **Voice:** "open the Nth one" (N ≤ 5) works through `fast_path` and the
  handler (`server.py` ~line 5704) once items carry `open`; on a `headlines`
  stage every copy phrase ("copy that", "copy the first one") copies the list
  (`fast_path` returns `("copy", 0)`; the handler finds `vis["copy"]`).
- **Settings file:** stage key `config: true` (bool, checked in `_check`)
  requires a `defaults.json` in the folder (regular file, JSON object ≤
  16 KiB), hashed with the folder. The settings file is
  `config_dir() / "<id>.json"`, where `config_dir()` reads `XDG_CONFIG_HOME`
  (else `~/.config`) **at call time** + `/nixi-companion/plugin-config`;
  opened `O_NOFOLLOW|O_NONBLOCK`, regular, ≤ 16 KiB, a JSON object → stdin
  `config`. Missing → the defaults, read from the **snapshot**
  (`tmp/plugin/defaults.json`, the bytes that were hashed); bad → the
  defaults and Settings shows "settings file unreadable". Not hashed, not in
  the snapshot. Consent card: "Nixi checks it again if any of its files
  change. Its settings (<path>) aren't checked: change them freely."
  Settings → Plugins: the path and an Edit button (create from the defaults
  with `O_WRONLY|O_CREAT|O_EXCL|O_NOFOLLOW`, mode `0600`, then `xdg-open`).
- **The `news` plugin** (`plugins/examples/news/`): phrases `news`, `the
  news`, `what's the news`, `what is the news`, `headlines`, `the
  headlines`; `network: true`; `config: true`; `cache_seconds: 300`; feeds
  from `config.feeds` (≤ 8 `{name, url}`); defaults BBC News
  `https://feeds.bbci.co.uk/news/rss.xml`, The Guardian
  `https://www.theguardian.com/uk/rss`, Hacker News
  `https://hnrss.org/frontpage`. Its own copy of the URL rules (it can't
  import `app/stages.py` in the sandbox) for every feed URL and every
  redirect target. All feeds at once (threads), **1.5 s per feed** (see
  Deviations) and a 2 MiB read cap; failed feeds counted in `source` ("1
  couldn't be reached"); all failed → a one-line `facts` card. RSS 2.0 and
  Atom with `xml.etree`; titles unescaped, tags stripped; `pubDate` via
  `email.utils`, Atom `updated`/`published` as ISO 8601. Dedupe by link
  (fragment and `utm_*` removed), then normalised title; newest first,
  undated last; top 5. `say` "Top stories: " + the first three titles with
  sources, cut to 200 at a word boundary, never "I read…". `parse_feed`,
  `merge`, `say_line` and `url_ok` are importable functions.
- **`rss-headlines`** phrases become `rss headlines`, `rss feed`.
- **`press` set:** off-white paper, no ruled lines; masthead "News" + date
  over a double rule; serif headlines (`Georgia, serif`); small-caps
  `SOURCE · age` under each (page-computed from `at`, refreshed each minute;
  "time unknown"); Open as a real `<button>` named "Open: <title>" posting
  `/api/stage/act {token, act: "open"}`; hairlines; ~340 px; entrance "press
  slip": an 18 px strip slides out (220 ms), unfolds once (`rotateX` 70°→0°
  about its top, 260 ms), rows fade in 40 ms apart; none under `REDUCED`;
  contrast ≥ 4.5:1; Esc closes; collapses to its tab after 30 s like other
  interactive stages; `stageText()` branch ("headline — source, age").

## Deviations (from the spec, made in this plan, covered by plan approval)

- **Per-feed timeout 1.5 s, not 2.2 s.** A network plugin's start (routes,
  pasta, bwrap, Python) takes 0.5–0.9 s of the 3 s limit (`TIME_DEFAULT`,
  `plugins.py:429`; agy's review), so 2.2 s per feed would time the whole run
  out.

- **`headlines` is plugin-only** (carried from the #166 review,
  2026-11-04): #166 added `stages.PLUGIN_ONLY` after agy found the agent
  could send a `gauges` board from its own `<<stage>>` block. Step 2 adds
  `"headlines"` to `PLUGIN_ONLY` (a test: the agent's block is refused, a
  plugin's output passes), so the agent can't make up stories with
  links.

- **Step 3, Edit on an existing settings file (implementation, 2026-11-04):**
  when the file exists, Edit opens it only if `lstat` says it is a regular
  file; a planted link or special file is refused ("couldn't open the
  settings file") and never handed to `xdg-open`. The plan named only the
  create flags. `xdg-open` failing is reported the same way.
