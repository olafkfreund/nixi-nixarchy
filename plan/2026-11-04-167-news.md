# Plan: News gets its own popout and animation

## Approved decisions (from the spec, so this file stands alone)

- **Code:** `olafkfreund/nixoarchy-snowflake`, branch `feat/167-news` from
  `main` (after PR #32, and after #166 if it has landed), worktree
  `../nixoarchy-snowflake-167`. Artifacts in nixi-nixarchy.
- **`say`:** shared with #166, word for word: every plugin kind may carry
  `say` (≤ 200 chars); `Store.put()` pops it from the page copy only;
  `plugin_stage()` returns `st.get("say") or "Here you go."`; the agent path
  ignores it. If #166 step 1 is already on `main`, step 1 here is skipped.
- **`headlines` kind:** `{v, kind, title ≤ 80, say?, source? ≤ 120,
  items[1–5]}`; item `{title ≤ 160, source ≤ 40, at: type int and > 0, or
  null (future > 10 min → null), url?}`; a bad URL is dropped, not refused.
- **`news_url_ok(u)`:** ≤ 400 chars, no whitespace/control; `https`; no `:`
  or `@` in the netloc; host lowercased and `rstrip(".")`; labels
  `[a-z0-9-]{1,63}`, no empty label, ≥ 2 labels, last label `[a-z]{2,63}`; not
  `localhost` nor ending `.localhost .local .lan .home .internal .home.arpa
  .ts.net`. No DNS check at open time; the spec states what this does and
  doesn't promise.
- **Tokens:** each safe item → `open` = `("link", {"url"})`, the page item has
  no `url`; one list copy token under `page["copy"]`.
- **Voice:** "open the Nth one" (N ≤ 5) works through the existing
  `fast_path` and handler; `fast_path` returns `("copy", 0)` for
  "copy that/it/this" on `headlines`.
- **Config:** stage key `config: true` requires a hashed `defaults.json` (in
  the folder, regular, JSON object ≤ 16 KiB); the settings file
  `$XDG_CONFIG_HOME|~/.config/nixi-companion/plugin-config/<id>.json`,
  opened `O_NOFOLLOW|O_NONBLOCK`, regular, ≤ 16 KiB, object → stdin `config`;
  missing or bad → the defaults (bad also shows "settings file unreadable");
  not hashed. Consent card: "Its settings (…) aren't checked: change them
  freely." Settings shows the path and Edit (create from defaults with
  `O_WRONLY|O_CREAT|O_EXCL|O_NOFOLLOW`, `0600`, then `xdg-open`).
- **The `news` plugin:** phrases `news`, `the news`, `what's the news`,
  `what is the news`, `headlines`, `the headlines`; `network: true`;
  `config: true`; `cache_seconds: 300`; feeds from `config.feeds` (≤ 8
  `{name, url}`); defaults BBC News, The Guardian, Hacker News; feed URLs and
  redirect targets checked with the `news_url_ok` rules; threads, 2.2 s and
  2 MiB per feed; failed feeds counted in `source`; all failed → one-line
  `facts`; RSS 2.0 and Atom via `xml.etree`; dedupe by link (no fragment, no
  `utm_*`) then normalised title; newest first, undated last; top 5; `say`
  "Top stories: …" ≤ 200 at a word boundary; parse/merge are importable
  functions.
- **`rss-headlines`:** phrases become `rss headlines`, `rss feed`.
- **`press` set:** off-white paper, no ruled lines; masthead "News" + date
  over a double rule; serif headlines (`Georgia, serif`); small-caps
  `SOURCE · age` (page-computed from `at`, refreshed each minute; "time
  unknown"); Open as a `<button>` named "Open: <title>"; hairlines; ~340 px;
  entrance "press slip": an 18 px strip slides out (220 ms), unfolds once
  (`rotateX` 70°→0° about the top, 260 ms), rows fade in 40 ms apart; none
  under `REDUCED`; contrast ≥ 4.5:1; Esc closes; `stageText()` branch.

## Steps

Each step is one commit on `feat/167-news`, made by the lead after the coder
reports done. Line numbers are from `main` after PR #32; re-find them by the
quoted code.

**1. `say` (shared; skip if #166 step 1 is on `main`)** — codex
- As #166 plan step 1: `validate()` keeps `say` for `facts`; `Store.put()`
  pops it from the page copy; `plugin_stage()` returns it.
- Check: `python3 -m unittest tests.test_stages tests.test_plugin_routes`.
- Traps: identical code to #166 step 1, so the second branch to land merges
  cleanly or drops its copy.

**2. `headlines`, the URL check, tokens, voice copy** — codex
- `app/stages.py`: `news_url_ok()` beside `item_url_ok()` (~line 189);
  `validate()` `headlines` branch; `Store.put()` `headlines` branch (before
  the final `facts` `else`); `fast_path()` (~line 429) copy rule for
  `headlines`.
- `app/plugins.py` ~line 702: add `"headlines"` to the accepted kinds.
- Tests (`tests/test_stages.py`): every case in the spec's verification list
  for `validate`, `news_url_ok`, `Store.put` and `fast_path`, including
  `2130706433`, `0x7f.0.0.1`, `localhost.` and `box.ts.net.`.
- Check: `python3 -m unittest tests.test_stages tests.test_plugin_routes`.
- Traps: `bool` is an `int` in Python; `urlsplit` lowercases nothing and
  keeps a trailing dot.

**3. The settings file** — coder
- `app/plugins.py`: `config` in `STAGE_KEYS` (~line 27); `_check` (~line 145)
  validates it and `defaults.json`; `CONFIG_DIR`; read the settings file in
  `_launch` (~line 640) and add `feed["config"]`.
- `app/server.py` `plugins_act()` (~line 1820): an `edit_config` action
  (create with `O_EXCL|O_NOFOLLOW`, `0600`, then `xdg-open`); the plugins
  list carries the path and an "unreadable" note.
- `app/static/index.html`: Settings → Plugins shows the path and Edit
  (~line 3135, `plugAct`); the consent card line (~line 3129).
- Tests (`tests/test_plugins.py`, `tests/test_plugin_routes.py`): missing,
  symlink, FIFO, oversize, non-object; not hashed (edit → still on); `_check`
  without `defaults.json`; Edit refuses a planted symlink.
- Check: `python3 -m unittest tests.test_plugins tests.test_plugin_routes`.
- Traps: derive the path from `XDG_CONFIG_HOME` (tests set it to a temp dir);
  the snapshot copy (`_snap`) must not include the settings file.

**4. The `news` plugin** — coder
- `plugins/examples/news/`: `plugin.json`, `defaults.json`, `run`
  (`parse_feed`, `merge`, `say_line`, a redirect handler that only follows
  URLs passing the check), `README.md`, `LICENSE` (as the other examples).
- `plugins/examples/rss-headlines/plugin.json`: the new phrases.
- Tests: `tests/test_news_plugin.py` (new) imports `run`'s functions: RSS and
  Atom samples, merge and dedupe, refused feed URL and redirect, `say`
  length; `tests/test_plugin_sandbox.py`: the plugin in the real sandbox with
  no reachable feeds returns the one-line `facts` within the limit.
- Check: `python3 -m unittest tests.test_news_plugin tests.test_plugin_sandbox`.
- Traps: `run` has no `.py` extension, so import it with
  `importlib.machinery.SourceFileLoader`; keep the whole run inside 3 s.
