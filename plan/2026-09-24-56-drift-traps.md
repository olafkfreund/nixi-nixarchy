# Plan: Three claims nothing checks

Approved decisions: bring `systemd/nixi-watch.service` into line with the module
on ordering and restart policy (not on `ExecStart`/`PATH`, which differ by
design); make `flake.nix:35` describe the assertions that exist; assert
`button/manifest.json`'s version rather than duplicating it in hope; and hold
all three together with a test in `checks.selfcheck` rather than a new CI job.

## Steps

1. `systemd/nixi-watch.service`: add `PartOf`/`After=graphical-session.target`,
   change `WantedBy` to `graphical-session.target`, `RestartSec` 5 -> 2.
2. `flake.nix:35`: "assets non-empty" -> "every shipped file non-empty".
3. `nix/package.nix`: assert `button/manifest.json`'s `version` equals the
   package version; add `jq` to the argument list.
4. `tools/test_nixi.py`: `test_unit_parity()` comparing the fields that must
   match across both definitions, plus the two version files and the flake
   comment.
5. Prove each assertion fails when broken.

## Deviation, found during implementation

**`systemctl enable` does not remove a previous `[Install]`'s symlinks.** The
spec flagged this as "worth confirming rather than assuming", and confirming it
showed the fix would not have reached existing machines: `enable_now` in
`install.py` ran `daemon-reload` then `enable --now`, which adds
`graphical-session.target.wants/` and leaves `default.target.wants/` in place.
The unit would still have started before the shell existed -- the exact bug,
surviving its own fix.

`enable_now` now runs `disable` first, ignoring failure since not-yet-enabled is
the normal first install. This was not in the plan because the spec had only
identified it as a question.

## Tests

```bash
python3 tools/test_nixi.py          # includes test_unit_parity
nix flake check --print-build-logs  # runs it, plus the new build assertion
ruff check --select=F,B,E9,E71,E72 install.py tools/
```

Each new assertion was deliberately broken and observed to fail:

| broken | message |
|---|---|
| `RestartSec` 2 -> 5 | `nixi-watch.service RestartSec=5, expected 2` |
| `WantedBy` -> `default.target` | `WantedBy=default.target, expected graphical-session.target` |
| button version -> 0.11.0 | `button/manifest.json is 0.11.0, manifest.json is 0.10.0` |
| the stale flake claim restored | `flake.nix claims an assertion that is not there` |

Runtime, not run: after `install.py` on a machine that already had the unit,
`systemctl --user show nixi-watch.service -p WantedBy -p After` must report
`graphical-session.target` and no leftover `default.target.wants/` symlink.

## Rollback

`git revert`. The unit file and comment are inert. The `install.py` change makes
upgrades disable-then-enable, which is idempotent and safe to revert; a machine
upgraded under the new code keeps correct symlinks afterwards either way.
