# Plan: one thing on stage — a Linux terminal for working agents, and no more stacked reactions

Issue #227 (olafkfreund/nixi-nixarchy). Intent and spec approved (`ff7d1e9`, `ccd2704`). This plan is self-contained.

## What we're building (approved decisions)

- **One focus** at a time, derived by `stageFocus(now)` → `answer | event | work | media | ambient`, in that priority.
  - `answer`: `pendingAppr`; `pwEl.classList.contains('on')`; `apEl.classList.contains('on')`;
    `MIR.owner==='pending'`; `notifyRow&&notifyRow.card&&notifyRow.span.isConnected`; `stgOpen()`;
    `!$('#musCard').hidden`.
  - `event`: `now < evUntil`. `evHold(ms)` sets `evUntil=Math.max(evUntil, now+ms)`.
  - `work`: `CP.working()` = agent map not empty, or his own **tool** run active (`running||q.length>0`; not `busy`).
  - `media`: `sitOn.music||sitOn.video`. `ambient`: otherwise.
- `focusSync()` runs from `frame()`; only on change it sets `document.body.dataset.focus` and calls `rxCheck()`,
  `CP.sync()`, `musSync()`.
- The agent **ask** mark (`AM`) stays a cue in every focus and is **not** part of `answer`.
- Reactions: each id maps to a focus — `music`,`video`→media; `load`,`memory`,`rain`,`snow`,`wind`,`meeting`→ambient;
  all others→event. `rxPaint` paints one id: `RX` if its focus is current, else the sustained one for the focus
  (media: video>music; ambient: load>memory). `r-<id>` only for that id. Event reactions call `evHold`.
- Looks: glasses/shades/tie/hats/scarf only in `ambient`; headphones only in `media`; weather marks only in `ambient`.
  `musBox()` keeps meaning "music on" (♪ chip shows except in `answer`); headphones use new `boomPainted()`.
- Beside him: `answer` items > mail pop-out > terminal. Terminal `.on` only in `work`; `mailPop` doesn't pop out in
  `answer`.
- Terminal: agent `Map` keyed `from|project`; updated always; `done`/`ask` end an entry (empty project → all of that
  agent); 15-min prune; `hide()` keeps the map; his own runs return to the agents view. Look: dark fixed colours
  (`#0d1117`/`#c9d1d9`/`#30363d`), radius 6px, no tail, no tilt, title bar with dots + one icon per agent (cloned
  from `#amC/#amX/#amA`, ids and `display` stripped; unknown → initial in a rounded square); one status line per entry
  `$ <agent> · <project> · <m>m` (max 4, then `+N more`), rewritten only when the minute changes (15 s timer); a
  decorative CSS-scrolled block of dim bars; `mini` removed. Calm hides sheet, keyboard, code eyes (CSS). Bar shows
  status text only. `idleActive()` includes `CP.working()`. `code_panel` off → no sheet/keyboard/eyes, focus still
  `work`.
- Nixi in `work` (not bar/hover/calm/goohide): `#codeEyes` in `#face`, sized from `faceBox` at `setCharacter`, given
  its own per-frame transform from the pupils' gaze/size; `#kbd` after `#accFront` at `BODY.pivot` + base anchor,
  paws tapping; new `working` mood (no sweat) above `idle` in `mood()`; static reduced-motion rule for
  `#code *, #codeEyes *, #kbd *`.
