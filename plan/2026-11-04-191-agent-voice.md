# Plan: Agent turn summaries spoken by Nixi

## Approved decisions

- Built in, not a folder plugin. `agent-say` keeps the hooks, summariser and silence
  checks; NixOS keeps the keys and per-host settings.
- `agent-say` hands over the **whole** summary once and exits. The page owns the queue,
  each sentence, stopping and replay.
- **Old voice only if Nixi isn't running at all:** no `runtime.json`, connection refused
  or HTTP 404. Decided once per turn, before handing over. A later failure, a 403 or
  `no-page` is silent. A turn is never spoken twice.
- Hidden by you: silent. Idle-hidden: he pops back and speaks. Do Not Disturb, quiet, a
  call or a meeting: silent, and one starting mid-summary stops it after the sentence.
- Cap reached or his voice unavailable: the summary stays as text, never another voice.
- Summaries wait until he's free. Up to 3 queued; the oldest beyond that, and any not
  started in 120 s, go to replay only. A sentence has a 30 s guard.
- Click, Space and Esc during a summary stop only the speech: no `/api/stop`, no mic.
- One alert per turn: the existing `attention` hook stays, and a summary adds no chime.
- Controls: mute per agent, replay of the last 5 (memory only), "Tell me more" (newest
  turn), by key and from Nixi.
- Only the summary reaches Nixi. Hand-off uses `tool_token`, never the full token.
- `speaker` option defaults to `"agent-say"`; p620 and razer switch after a live check.

Decision made here: the strict flag is a `Speaker.strict` set of sids, not an eighth
field. The `todo`, `ready` and `making_item` tuples are unpacked by position in several
places, and a new field would touch all of them.

## Deviations (after code review)

Opus, Codex and agy reviewed the code; agy's run ended with status ERROR, so it was used for leads only. These changes follow:

- Step 3: `agentNext()` became `agentTick()` on a 250 ms interval. It also rechecks "is he busy" before every sentence and after every await, and drops the rest of a summary if `sayEpoch` changed, which means something cut him off. One `nextReply()` per summary.
- Step 2: `/api/agent-say/check` takes `{from}` and applies `agent_say_ready` too, so a meeting or a mute mid-summary stops it. `/api/agent-say/more` takes `{turn}`. A long name is cut, and a secret-looking name is dropped, rather than refusing the summary.
- Step 4: Replay goes through `agentQ`, not `enqueue`, so stop, `/check` and the guard apply.
- Step 5: `more [turn]` stops if that turn is no longer the last, and checks `held` and `nixi_ready` before the long summary. Summaries are trimmed to 2000 characters at a sentence end.

- Step 3, final review: the sentence guard is 30 s plus 150 ms per character (Codex reproduced a long valid sentence being cut off). "Stop" (`barge`) and the push-to-talk hotkey use `agentStop`, so the queue clears with no `/api/stop`; push-to-talk then opens the mic, as it always does. Muting partway stops without reprinting.
