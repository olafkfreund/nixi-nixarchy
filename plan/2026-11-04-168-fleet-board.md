# Plan: The system board shows the user's other machines

## Approved decisions (from the spec, so this file stands alone)

- **Repos and order:** (A) `olafkfreund/nixoarchy-snowflake`, branch
  `feat/168-fleet-board` from `main` **after #166 is merged** (it builds on
  #166's `gauges` kind, `term` set, `stage_update`, `Store.replace` and
  `system_status()`); worktree `../nixoarchy-snowflake-168`. (B) this repo,
  branch `feat/168-fleet-board` (artifacts and `nix/hm-module.nix`). (C) the
  user's NixOS config `~/.config/nixos`, branch `feat/nixi-168-fleet`. A ships
  first, then B, then C (C bumps the `nixi-companion` and `nixarchy` inputs).
- **Fleet (tailnet IPv4, from `tailscale status`, 2026-11-04):** p620
  `100.69.100.115` (companion), p510 `100.118.96.32` (answers only), razer
  `100.90.72.124` (companion). Reached by address only, never by name
  (`p510` resolves to the LAN `192.168.1.65`; MagicDNS fails on p620).
- **Token (amended decision 2):** one agenix secret `nixi-status-token`
  (32 random bytes, base64) on every fleet host; owner root on p510; owner
  `olafkfreund`, mode 0400 on p620 and razer. It stops everything except the
  user's own programs. No token, secret or path in any environment variable.
- **`nixi-status` (A, `app/status_serve.py`, `bin/nixi-status`):**
  `ThreadingHTTPServer` bound to this host's tailnet address only; `GET
  /v1/status` only (else 404); source address must be exactly one of
  `allowedCallers`, then `Authorization: Bearer` must match
  (`hmac.compare_digest`), else 403 with one fixed body; ≤ 4 requests at once
  (else 503), 256 KiB thread stacks, 2 s socket timeout; `log_message`
  silenced (start-up and crashes only). Returns ≤ 16 KiB JSON from
  `system_status(user=False)`: `host, cpu_pct, mem, disks, net, uptime_s,
  failed_system, generation, rev, built` and `failed: null`.
- **NixOS module (A, `nixosModules.status`):** `services.nixi-status =
  { enable = false; address; port = 9188; allowedCallers = [ ]; tokenFile; }`;
  `DynamicUser`, `LoadCredential=token:<tokenFile>`, `ProtectSystem=strict`,
  `ProtectHome`, `PrivateTmp`, `NoNewPrivileges`, `CapabilityBoundingSet=`,
  `RestrictAddressFamilies=AF_INET AF_UNIX`, `MemoryMax=64M`,
  `Restart=always`, `RestartSec=5`, after/wants `tailscaled.service`, `path`
  has systemd; port only in
  `networking.firewall.interfaces.${config.services.tailscale.interfaceName}.allowedTCPPorts`;
  assertions: tailscale enabled, `address` and `tokenFile` set,
  `allowedCallers` non-empty, every entry in `100.64.0.0/10` and not
  `100.100.100.100`.
- **`system_status()` (A):** adds `rev` (`configurationRevision` from
  `/run/current-system/sw/bin/nixos-version --json`, else `null`) and `built`
  (mtime of `/nix/var/nix/profiles/system`, ISO 8601), cached per
  `/run/current-system` target; `user=False` skips `systemctl --user` and
  gives `failed: null`; a last reading older than 30 s counts as none (250 ms
  double read); callers within 1 s share one reading.
- **Collector (A, `app/peers.py`):** `snapshot()` returns at once and starts a
  background round if none runs; one round at a time; each peer via
  `http.client.HTTPConnection(address, port, timeout=1.5)`, no DNS, no
  redirects, non-200 = failure; round ends by 2 s; answers ≤ 16 KiB, JSON,
  typed per key, else `down` "gave an answer Nixi can't read"; per peer
  `{name, state up|down|asking, status, last_ok}` (memory only; `asking`
  before the first answer). A round ending while a live board is open
  refreshes it server-side (`Store.replace` → `stage_update`).
- **Consent and withdrawal (A):** `reads` accepts `peer-status`; `_check`
  refuses it with `network: true`. `feed["peers"]` only when declared,
  allowed (#149) and the **"Other machines"** switch (Settings → Plugins, off
  by default, shown only with a peer configured) is on. While off, a board
  from a `peer-status` plugin gets "2 other machines · Show them · Not now";
  either button sets `peers_asked` and the line never returns; "Show them"
  turns the switch on. Turning it off: stop the collector, drop a round in
  flight (round counter), clear results and `last_ok`, drop the plugin's
  `plugins._cache` entry, close an open board with peers (`STAGES.close()`
  *and* `BUS.pub(t="stage_close")`, with a toast "Other machines are off"),
  so nothing stays on screen. Turning it on: drop the same cache entries and
  refresh an open board server-side, so peers show "asking…" at once and
  arrive within about 2 s. `plugin_caps(m)` and the folder consent card name
  `peer-status`: "It can read your other machines' status". A plugin with any
  `reads` has its stderr text dropped from the log (length only).
  `feed["peers"]` never reaches the agent.
- **`nix-status` (A):** `reads: ["system-status", "peer-status"]`; this host
  as #166 plus `rev` / `built` badges; then peers in fleet order, ≤ 6 hosts:
  `up` → CPU, MEM, /, STORE meters, `rev` / `built` / `up` badges, "Failed
  (system)" list, badge `user —`; `asking` → `state: "stale"`, badge
  "asking…"; `down` → badge `last` "not seen yet" / "HH:MM". A differing
  `rev` (full strings compared; a `-dirty` suffix shown as "dirty") → tone
  `warn`, "≠ a1b2c3d"; `null` on either side → "—". `say`: one
  problem list, this host first in #166 wording, peers without unit names
  ("p510 has one failed service.", "razer is off.", "p510 is on another
  revision."); all fine with a peer up → "All machines look fine."; no peers
  → #166's line; ≤ 200 chars then "and N more."; `asking` isn't a problem.
- **Page (A, `term` set):** this host full; each peer a compact panel (badges,
  one row per meter, no sparkline, failed count), a button with
  `aria-expanded`, Enter/click expands one; history kept per host; `down` /
  `asking` one dim line ("┤ razer ├ unreachable · not seen yet"); ≤ 340 px,
  scroll inside; 1 full + 2 compact fit at 1080p; `stageText()` reads all
  hosts; #166's reduced motion, contrast, Esc.
- **HM module (B):** `services.nixi.companion.peers` (list of `{ name,
  address, port ? 9188 }`, default `[ ]`) and `peerTokenFile` (path or null);
  writes `~/.config/nixi-companion/peers.json` `{peers, token_file}` only when
  `peers != [ ]`.
- **Host config (C):** `nixiFleet` in `hosts/common/nixos/nixi-fleet.nix`;
  each host enables `nixi-status` only if `networking.hostName` is in it, with
  its own `address` and the *other* companions as `allowedCallers`; p620 and
  razer set `peers` to the other two hosts and `peerTokenFile`;
  `system.configurationRevision = inputs.self.rev or inputs.self.dirtyRev or
  null` for all hosts (the outputs don't bind `self`).
