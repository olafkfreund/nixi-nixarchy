# Plan: keep the window token out of server.log

## Decisions (from the approved spec)

- The window loads `http://127.0.0.1:<port>/?native=1`, with no fragment,
  ever.
- It hands the page the token through a WebKit2 4.1 user script:
  `WebKit2.UserScript.new(source, TOP_FRAME, START, ["http://127.0.0.1:<port>/*"], None)`,
  where the source is `window.__nixiT=<json token>;`. Before each load, it
  removes old scripts with `remove_all_scripts()`.
- `token_script(tok, port)` is a pure helper that returns
  `(source, allow_list)`.
- The page reads `window.__nixiT` first and then deletes it. `#t=` and
  `#ticket=` stay.
- `load-failed` on a URI under the server's origin retries after 1 s: it
  reads the token again, hands it over and loads, and returns `True`.
- Console-to-stdout stays on. No ticket, no log scrubber, no stdout
  filtering.

All code is in olafkfreund/nixoarchy-snowflake. Work in a new worktree,
`../nixoarchy-snowflake-181`, on branch `fix/181-token-in-log` from
`origin/main`.

## Steps

**1. `app/window.py`: hand the token by user script** (coder: Codex)
- Add `token_script(tok, port)` at module level:
  `return f"window.__nixiT={json.dumps(tok)};", [f"http://127.0.0.1:{port}/*"]`.
  The port is taken from `urlparse(self.url).port`.
- `_authed_url()` (~line 1252) becomes `_token()`. It returns the token
  string, with the same 5 s wait, or `""` after logging what it logs today.
- Add `_hand_token()`:
  - `self.ucm.remove_all_scripts()`;
  - when the token is non-empty, `add_script(WebKit2.UserScript.new(src,
    WebKit2.UserContentInjectedFrames.TOP_FRAME,
    WebKit2.UserScriptInjectionTime.START, allow, None))`.
- Line 367: keep `ucm` as `self.ucm`.
- Line 392 `v.load_uri(self._authed_url())` and line 1271 (`reauth`) become
  `self._hand_token(); self.view.load_uri(self.url)`.
- Next to line 391, connect `load-failed`:
  `(view, ev, uri, err)`. If `uri` starts with the server's origin, call
  `GLib.timeout_add(1000, …)`, which does a hand-and-load and returns
  `False`. Return `True` either way only for the server's origin, `False`
  otherwise.
- Check: `python3 -c "import ast,sys; ast.parse(open('app/window.py').read())"`
  and `grep -n '#t=' app/window.py` (no matches).
- Traps:
  - a window that loads before `self.url` is set: set `self.url` before the
    first `_hand_token()` (today it's set at line 390, before 392, so keep
    that order);
  - never log or print the token;
  - Codex has read-only shell access in its sandbox, so make edits with its
    file tools.

**2. `app/static/index.html`: page intake** (coder: Codex)
- In `tokenReady` (~line 950), before `if(h.get('t'))`, add
  `if(window.__nixiT){ TOKEN=String(window.__nixiT); delete window.__nixiT; } else `.
- Check: `grep -n '__nixiT' app/static/index.html` (2 hits: the read and the
  delete).
- Traps: keep the `sessionStorage` save that follows (it runs when `TOKEN`
  is set). Don't touch the `#t=` and `#ticket=` branches.

**3. Tests** (coder: the Sonnet coder)
