# Plan: Let each user choose Nixi's language (English, Norwegian, Polish)

## Approved decisions (the spec plus its binding revisions)

- **Code:** fork, branch `feat/177-language` from `main` after #175 and #176
  have merged (all three edit Settings), worktree `../nixoarchy-snowflake-177`.
  Line numbers are from the code map; re-find them by name.
- **`LANGS`:**
  - `en`: whisper `en`, locale `en`, date `en-GB`;
  - `nb`: whisper `no`, locale `nb`, date `nb-NO`;
  - `pl`: whisper `pl`, locale `pl`, date `pl-PL`.
- **The setting:** `language` ∈ `en|nb|pl` via `/api/settings`, in
  `state_info` with `lang_active` and `lang_status`.
  - An existing config keeps its value.
  - Only a first run (no `config.json`) reads `LC_ALL`, then `LC_MESSAGES`,
    then `LANG` (ignoring `.UTF-8`): `nb_NO`/`no_NO`/`nn_NO` → `nb`, `pl_PL`
    → `pl`, anything else → `en`.
  - There is no "Automatic".
- **Requested vs active:** `language` is the requested language; `lang_active`
  is the one in use.
  - Everything uses `lang_active`: transcription, wake and stop words,
    voice, the reply clause, shortcuts and lines.
  - The switch completes only when both the new Whisper model and the new
    voice are ready; `lang_active` then flips under a switch lock.
  - The switch generation `sg` is bumped on each request; a superseded load
    is discarded.
  - Settings shows "Switching to <Language>: downloading speech model /
    voice…", and he says once that he'll switch when ready.
- **Whisper:**
  - for `en`, `auto` stays `small.en` (CUDA) / `base.en` (CPU); for `nb` and
    `pl`, `auto` is `small` (CUDA) / `base` (CPU);
  - `whisper_model` (5521) also accepts `tiny|base|small|medium`, and a `.en`
    model with `nb` or `pl` is refused;
  - transcription passes `language=LANGS[lang_active].whisper`;
  - the CPU fallback replaces `_whisper` only if it is still the object that
    failed (an identity check under `_whisper_lock`).
- **Hints and filters:**
  - `stt_hint` per language, starting with the wake phrase;
  - per-language hallucination lists (pl "Napisy stworzone przez społeczność
    Amara.org", "Dziękuję."; nb "Teksting av", "Takk for meg.");
  - the mic-test hint names the language.
- **Wake:** `WAKE_RE` (2931) and quick.py's name list (322) accept the
  greetings `hey|hi|okay|ok|yo|oi|hei|hallo|hej|cześć`. The wake transcription
  hint is the active language's wake phrase.
- **Stop:** `STOP_RE` (2857) is English ∪ the active language, and accepts the
  leading wrappers `hei nixi|hej nixi|cześć nixi`.
  - nb: `stopp|vent|vær stille|hysj|det holder|takk|ok takk`;
  - pl: `stop|czekaj|poczekaj|cicho|ciszej|wystarczy|dzięki|dziękuję`.
- **Normalisation** (`stages.fast_path` 642, `plugins.norm` 35):
  `unicodedata.normalize("NFC", s).casefold()`, then `re.sub(r"[^\w ]|_", "
  ", …)`.
- **Shortcuts:** `app/lang/<code>.json` holds `verbs → canonical`, `ordinals`,
  `cardinals`, `fillers`, `it`, `nouns` and `plain`. `_ACT`, `_ORD` and
  `_PLAIN` are built from English ∪ the active language, and `fast_path`
  returns canonical actions.
  - **nb:**
    - verbs: kjør→run, kopier→copy, åpne→open, spill / spill av→play;
    - ordinals: første, andre, tredje, fjerde, femte;
    - cardinals: en, to, tre, fire, fem;
    - fillers: den, det, nummer;
    - it: den, det;
    - nouns: video, klipp;
    - plain: lukk→close, gå tilbake→back, vis den / vis det→show.
  - **pl:**
    - verbs: uruchom→run, skopiuj / kopiuj→copy, otwórz→open, odtwórz /
      puść→play;
    - ordinals with all forms:
      pierwszy/pierwszą/pierwsze/pierwszego … piąty/piątą/piąte/piątego;
    - cardinals: jeden, dwa, trzy, cztery, pięć;
    - fillers: numer;
    - it: to, ten, tę, tą, go;
    - nouns: wideo, klip, film;
    - plain: zamknij→close, wróć→back, pokaż / pokaż to→show.
  - `reserved()` checks every language.
- **quick.py** is not translated in v1.
- **Lines:** `t(key, **slots)` with an English fallback. Covered:
  - the stage results (5809–5845);
  - `plugin_stage` (4673, 4689);
  - the pickers (4466, 4489, 4511);
  - `approval_say` (698) and `bridge_question` (692);
  - `speakable()`'s spoken replacements ("The rest is on screen.", "your
    Downloads folder"…).

  Quips are per language (`quips.nb.json`, `quips.pl.json`), with an English
  fallback per event. The page-spoken lines come from `state_info.lines`.
- **The agent:** one `lang_clause()` ("Reply in Norwegian (Bokmål)." / "Reply
  in Polish.", empty for English) goes into all four paths:
  - the bridged note (4546);
  - `FOLLOW_NOTE` (2860);
  - the non-bridged `run_claude`/`build_cmd` prompt;
  - `summarize_command`.
- **Voices:**
  - for `nb` and `pl`, `auto` skips Kokoro, and an explicit Kokoro gives
    "Kokoro has no Norwegian/Polish voice";
  - the piper voices per language are nb `no_NO-talesyntese-medium` and pl
    `pl_PL-gosia-medium`, `pl_PL-darkman-medium`, `pl_PL-mc_speech-medium`;
  - espeak uses `-v nb` / `-v pl`, and Robot `nb+m3` / `pl+m3`;
  - `voice_by_lang` remembers the voice per language;
  - ElevenLabs (#176) voices speaking the language are listed first.
- **Plugins:** `locale=LANGS[lang_active].locale` at both callers (4675,
  4767), and in the `run_stage` cache key.
- **Dates:** in the page (2482), the active date locale.

## Revisions after review (binding; these override the steps above where they differ)

Codex (gpt-6-sol) and agy (model not reported) reviewed the draft. Each
finding was checked against the code.

1. **Order and the safe intermediate state.** Steps 3 and 4 swap places: step
   3 is now **voices and plugins** (coder), and step 4 is now **listening and
   the switch** (codex).
   - From step 1 on, `language` can be saved, but `lang_active` changes only
     through the switcher. The switcher arrives in step 4, so until then
     `lang_active` stays what it was at start-up.
   - The Language chips only appear in step 6. No intermediate commit can
     put Nixi in a half-switched state.
2. **A voice-ready signal.** Step 3 adds `fetch_voice_sync(name, timeout)`,
   which downloads in the caller's thread and returns `(ok, reason)`. The
   step 4 switcher calls it for the new language's voice, and also loads the
   Whisper model. `lang_active` flips only when both succeed. A failure
   keeps the old language and shows the reason. The existing async
   `fetch_voice` is unchanged for other callers.
3. **Model and language as one pair.** `_stt = (model, lang, device)` is read
   once per transcription under `_whisper_lock`. `run_whisper` uses that
   tuple's language. The GPU-to-CPU retry builds its CPU model for the same
   language, and installs it only if `_stt` is still the pair it started
   with. Test: a switch that lands between the snapshot and the transcribe
   call leaves the old pair used for that utterance and the new pair for the
   next.
4. **Multi-word words.** `_ACT`, `_ORD` and `_PLAIN` are built from escaped
   alternations, sorted longest first, with spaces matched as `\s+`
   ("spill av", "gå tilbake", "pokaż to", "vis den"). Polish word order "numer
   dwa" works through the filler. The tests use "otwórz drugi" and "otwórz
   drugi artykuł" as the main Polish cases, with the `-ego` forms as extras.
   `tę` is the standard form, with `tą` also accepted.
5. **Stop before wake.** In `Wake.check` (3091–3096), while he is speaking,
   `STOP_RE` is tested **before** `WAKE_RE`, so "hei nixi stopp" or "hej nixi
   cicho" stops him and doesn't start listening. `plugins.norm` and
   `fast_path` also strip the leading wrappers `hei nixi|hej nixi|cześć nixi`,
   as they do "nixi" today.
6. **Quips per language:** `Quips.bags` is keyed by `(lang, event)`. A
   switch starts fresh bags. Test: the next quip after a switch is in the
   new language.
7. **Details now in the steps:**
   - step 4 asserts `language="no"` for nb;
   - Settings shows the first-switch size ("≈150 MB" for `base`, "≈480 MB" for
     `small`) and suggests `small` only with a GPU (step 6);
   - the live check measures CPU transcription time for a short command in
     pl and nb, and logs it in diagnostics;
   - the news README gets the topic-word note (step 5).
8. **Corrections:**
   - `WAKE_RE` is at 2930;
   - the path phrases come from `say_path()` (3224), not `speakable()`, so
     step 5 names it;
   - `lang_clause()`'s four paths are located by name in step 1, and its
     tests build each prompt;
   - the first-run default is written to `config.json` at once, so the
     second start doesn't re-detect.
9. **The page tests:** `tests/voice_fit.mjs` runs through its Python wrapper
   `tests/test_voice_fit.py`, which starts node with the CDP harness like
   `test_stages_fit.py` does. That wrapper is what `unittest` runs.
