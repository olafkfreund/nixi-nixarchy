# Plan: A dark system board for "system status"

## Approved decisions (from the spec, so this file stands alone)

- **Code:** `olafkfreund/nixoarchy-snowflake`, branch `feat/166-system-board`
  from `main` (after PR #32), worktree `../nixoarchy-snowflake-166`.
  Artifacts in nixi-nixarchy.
- **`say`:** every plugin kind may carry `say` (≤ 200 chars, `_str`).
  `Store.put()` pops it from the page copy only (the cached stage keeps it).
  `plugin_stage()` returns `st.get("say") or "Here you go."`. The agent path
  (`plugin_stage_thread`) ignores it. Shared word for word with #167: this
  plan builds it (step 1); #167's plan finds it.
- **`gauges` kind:** `{v, kind, title, say?, source?, live?, hosts[1–6]}`;
  host `{name [A-Za-z0-9._-]{1,32}, state up|down|stale, badges ≤ 6 {k ≤ 16,
  v ≤ 60, tone?}, meters ≤ 8 {label ≤ 12, pct 0–100|null, v? finite ≥ 0,
  text? ≤ 40, tone?}, lists ≤ 2 {title ≤ 24, items ≤ 5 × ≤ 80, tone?}}`;
  `tone` ok|warn|bad; `bool`, NaN, ±inf refused; `live` strictly bool.
- **Tokens:** copy under `page["token"]`; refresh under `page["refresh"]` =
  `("refresh", {pid, query})`, only when `live` and `plugin_stage` passes
  `refresh=(pid, query)` to `Store.put`.
- **`Store.replace(refresh_token, stage)`:** under the lock, only if the
  current entry holds that refresh token; same tokens; the copy token's text
  rewritten; time kept; else `None`.
- **`system_status()` adds** `failed_system`, `cpu_pct`, `mem {total,
  available}`, `disks [{path, total, used}]` for `/` and `/nix/store`,
  `net {rx_bps, tx_bps}` (not `lo`), `uptime_s`, `host`. Counters primed in
  `Plug.reload`; 250 ms double read only with no earlier reading; negative
  delta → `null`; both `systemctl` calls in parallel, 1 s each.
- **`_check` refuses** `network: true` together with
  `reads: ["system-status"]`. Consent card: "It can read your system status
  (load, memory, disks, network rates, failed services)". No re-consent.
- **Refresh:** page every 5 s while open and visible (`stgPosted`), not
  `document.hidden`, max 24, stop on `ok: false`. Server `stage_act(token,
  "refresh")`: current stage's refresh token only; refused if
  `Desk.locked()`; `run_stage(p, q, fresh=True)` (no cache read, no stale
  fallback, still writes the cache, still `Busy`); `Busy` → `{ok: True,
  skipped: True}`; `StageError` → `{ok: False}` (+ `Plug.reload()` on
  `CHANGED`); success → `Store.replace` then bus `stage_update`.
- **Page:** a `stage_update` handler updates the open board in place (no
  rebuild, entrance, focus move or timer reset). History in the page: 24
  values per host+label. `stageTick`: a refreshing `gauges` collapses after
  2 min without use; `idleShowing()` counts it as showing.
- **`term` set:** `info.theme` via `applyThemeVars`; `red`/`green`/`yellow`
  fall back to `#e06c75`/`#98c379`/`#e5c07b`; background at 96%; `var(--mono)`;
  one panel per host with the name notched into the top border; meter rows
  `LABEL ▕bar▏ value · text` + braille sparkline (8 levels, `aria-hidden`,
  row `aria-label` "CPU 18 percent"); "—" for null; contrast ≥ 4.5:1 or a
  fixed dark palette; ~340 px wide; scroll past 8 meters. Entrance "power
  on": `scaleY` from a 2 px line (180 ms), rows 30 ms apart, bars fill
  (200 ms); none under `REDUCED`.
- **`nix-status`:** a `gauges` plugin (CPU, MEM, /, STORE, NET ↓, NET ↑;
  `gen`, `up` badges; "Failed" list); `live: true`; `say`; `cache_seconds: 4`;
  phrases, `reads` and no-network unchanged; README notes "Changed" once and
  the needed Nixi version.
- **Budget:** refresh p95 < 400 ms on p620, < 800 ms on razer.

## Steps

Each step is one commit on `feat/166-system-board`, made by the lead after the
coder reports done (never mid-edit: the #94 lesson). Line numbers are from
`main` after PR #32; re-find them by the quoted code.

**1. `say` (shared)** — codex
- `app/stages.py` `validate()` (~line 76): `facts` keeps an optional `say`
  (`_str(say, 200)`; a bad `say` → `None`).
- `app/stages.py` `Store.put()` (~line 274): `page.pop("say", None)` right
  after `page = dict(stage)`.
- `app/server.py` `plugin_stage()` (~line 4631): `return True,
  st.get("say") or "Here you go."` (line ~4648).
- Tests (`tests/test_stages.py`, `tests/test_plugin_routes.py`): `say` kept by
  validate; over 200 chars refused; absent from the page event; still in the
  cached stage on a second ask; "Here you go." without it.
- Check: `python3 -m unittest tests.test_stages tests.test_plugin_routes`.
- Traps: `validate` builds a new dict from known keys; add `say` there, not
  by copying `obj`.

**2. `gauges` kind and tokens** — codex
- `app/stages.py` `validate()`: a `gauges` branch with every rule above;
  numbers via `type(x) in (int, float) and math.isfinite(x)`.
- `app/plugins.py` ~line 702: accept `("facts", "gauges")`.
- `app/stages.py` `Store.put(stage, refresh=None)`: a `gauges` branch (copy
  under `page["token"]`, the summary text; refresh token when `live` and
  `refresh`); `Store.replace(refresh_token, stage)` as decided.
- `app/server.py` `plugin_stage()`: pass `refresh=(pid, query)` to
  `STAGES.put`.
- Tests: each validation rule's bad case; `Store.replace` keeps tokens,
  updates the copy text, and returns `None` after `close()` or another `put`.
- Check: `python3 -m unittest tests.test_stages tests.test_plugin_routes`.
- Traps: the final `else` in `Store.put` assumes `facts` (`stage["points"]`):
  the `gauges` branch must come before it.

**3. Host readings and the network rule** — coder
- `app/plugins.py` `system_status()` (~line 554): the new keys; module-level
  last counters + time; `prime()` called from `Plug.reload` (`server.py`
  ~line 1739) for plugins with `reads: ["system-status"]`; `systemctl`
  calls in two threads, `timeout=1`.
- `app/plugins.py` `_check()` (~line 145): refuse `network: true` with
  `reads` containing `system-status`.
- `app/static/index.html` ~line 3129: the consent card's system-status line.
- Tests (`tests/test_plugins.py`): fake `/proc` dir (patch the paths as
  module constants); rates from two readings; counter reset → `null`;
  unreadable → `null`; a fake `systemctl` that sleeps 5 s returns within
  1.3 s; `_check` refusal.
- Check: `python3 -m unittest tests.test_plugins`.
- Traps: read `/proc` paths through module constants so tests can point
  them at a temp dir; never 0 for "unknown".

**4. Refresh** — codex
- `app/plugins.py` `run_stage(…, fresh=False)` (~line 587): with `fresh`,
  skip the cache hit and the stale fallback; still write the cache.
- `app/server.py` `stage_act()` (~line 4701): a `"refresh"` act as decided;
  publish `BUS.pub(t="stage_update", **stage_event(page))`.
- Tests (`tests/test_plugin_routes.py`): only the current refresh token;
  `Desk.locked()` true → refused; `Busy` → skipped; `CHANGED` →
  `Plug.reload` called and `ok: False`; refresh after `close` sends nothing.
- Check: `python3 -m unittest tests.test_plugin_routes tests.test_plugins`.
- Traps: `Ambient.locked` is not updated while `proactive` is off; call
  `Desk.locked()` (it may return `None`: treat as unlocked).

**5. The `term` set and the update loop** — agy
- `app/static/index.html`: CSS for `#stg.term` (near the other sets, ~line
  190–265); set choice for `gauges` (~line 2221–2223); a `stageTerm(ev, …)`
  renderer; the `stage_update` handler beside the `stage` one (~line 2058);
  the 5 s refresh loop with its stop conditions; `stageTick` (~line 2362) and
  `idleShowing()` (~line 3370) changes; `stageText()` gauges branch (~line
  2336); sparkline from history; the entrance and its `REDUCED` path.
- Check: headless Chromium with a fixture page state (as earlier stage work
  did): renders; `stage_update` changes values without the entrance; the loop
  stops on close, collapse, `ok: false`, 24; reduced motion.
- Traps: agy's sandbox has the worktree read-only, so edits go through its
  file tools; headless Chromium only with `--disable-gpu` (a GPU preview hung
  the AMD GPU on p620 twice); `REDUCED` is the existing media query const.

**6. `nix-status` as `gauges`** — coder
- `plugins/examples/nix-status/run`, `plugin.json` (`cache_seconds: 4`),

- Traps: keep `os.statvfs` as the fallback when `disks` is missing.
