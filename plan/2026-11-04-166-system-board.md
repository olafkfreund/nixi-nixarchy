# Plan: A dark system board for "system status"

## Approved decisions (from the spec, so this file stands alone)

- **Code:** `olafkfreund/nixoarchy-snowflake`, branch `feat/166-system-board`
  from `main` (`2e28c93`, after PR #32), worktree
  `../nixoarchy-snowflake-166`. Artifacts in nixi-nixarchy.
- **`say`:** every plugin kind may carry `say` (≤ 200 chars, `_str`).
  `Store.put()` and `Store.replace()` pop it from the page copy only (the
  cached stage keeps it). `plugin_stage()` returns `st.get("say") or "Here you
  go."`, spoken and shown as his caption; never in a prompt or Nixi's log. The
  agent path (`plugin_stage_thread`) ignores it. Shared word for word with
  #167: this plan builds it (step 1).
- **`gauges` kind:** `{v, kind, title ≤ 80, say?, source? ≤ 120, live?,
  hosts[1–6]}`; host `{name [A-Za-z0-9._-]{1,32}, state up|down|stale
  (default up), badges ≤ 6 {k ≤ 16, v ≤ 60, tone?}, meters ≤ 8 {label ≤ 12,
  pct 0–100|null, v? finite ≥ 0, text? ≤ 40, tone?}, lists ≤ 2 {title ≤ 24,
  items ≤ 5 × ≤ 80, tone?}}`; `tone` ok|warn|bad; numbers `type(x) in (int,
  float)` and `math.isfinite`; `live` strictly `True`/`False`; unknown keys
  dropped; a bad field → `None`. `pct: null` shows "—", never 0.
- **Tokens:** copy under `page["token"]` (`("facts", {"text": summary})`, the
  key and payload `stage_act` copy already reads); refresh under
  `page["refresh"]` = `("refresh", {pid, query})`, only when `live` and
  `plugin_stage` passes `refresh=(pid, query)` to `Store.put`.
- **`Store.replace(refresh_token, stage)`:** under the lock, only if the
  current entry holds that refresh token; same tokens; `say` popped; the copy
  token's text rewritten; time kept; returns the page, else `None`.
- **`system_status()` adds** `failed_system` (`systemctl --failed --plain
  --no-legend`), `cpu_pct` (`/proc/stat`), `mem {total, available}`
  (`/proc/meminfo`), `disks [{path, total, used}]` for `/` and `/nix/store`
  (used = `(f_blocks - f_bfree) * f_frsize`), `net {rx_bps, tx_bps}`
  (`/proc/net/dev`, not `lo`), `uptime_s`, `host`. Rates from the last
  counters kept in the module, primed by `prime()` when a `system-status`
  plugin is loaded; a 250 ms double read only with no earlier reading;
  negative delta → `null`; unreadable → `null`. The two `systemctl` calls run
  in parallel, `timeout=1` each.
- **`_check` refuses** `network: true` together with `reads` containing
  `system-status` ("a plugin that reads your system status can't use the
  network"). Consent card: "It can read your system status (load, memory,
  disks, network rates, failed services)". No re-consent for plugins already
  allowed.
- **Refresh, page:** every 5 s while the `gauges` stage is open
  (`stgState === 'open'`), shown (`stgPosted`), and not `document.hidden`;
  at most 24; stops on any `ok: false`.
- **Refresh, server:** `stage_act(token, "refresh")` for the current stage's
  `("refresh", …)` token only; refused (`ok: false`) if `Desk.locked()` is
  true (`None` counts as unlocked); `run_stage(p, q, fresh=True)` (no cache
  read, no stale fallback, still writes the cache, still `Busy`); `Busy` →
  `{ok: true, skipped: true}`; `StageError` → `{ok: false}` and on `CHANGED`
  `Plug.reload()`; `Store.replace` → `None` → `{ok: false, error: "gone"}`
  and nothing sent; success → `BUS.pub(t="stage_update", **stage_event(page))`.
- **Page update:** a `stage_update` handler updates the open board in place
  (no rebuild, entrance, focus move or timer reset); ignored with no `gauges`
  board open. History: last 24 values per host+label (`pct`, else `v`),
  dropped on close. `stageTick`: a *refreshing* `gauges` collapses after 2 min
  without use; once refreshing stops, the usual 30 s. `idleShowing()` counts a
  refreshing board as showing.
- **`term` set:** colours from `info.theme` through `applyThemeVars`, with CSS
  fallbacks on `#stg.term` for every variable `applyThemeVars` may remove
  (`--tbg`, `--ink`, `--inksh`, `--tacc`, `--tred`, `--tgreen`, `--tyellow`;
  red/green/yellow default `#e06c75`/`#98c379`/`#e5c07b`), since it removes
  them when the theme is off (`follow_theme === false`) or absent. Background
  at 96%; `var(--mono)`. One panel per host, the name notched into the top
  border ("┤ p620 ├"); badges on a line; meter rows `LABEL ▕bar▏ value ·
  text` (CSS bar) + a braille sparkline (8 levels, `⠀`–`⣿`, `aria-hidden`);
  row `aria-label` "CPU 18 percent"; lists below (failed in red); contrast ≥
  4.5:1 or a fixed dark palette; ~340 px; scroll past 8 meters. Entrance
  "power on": `scaleY` from a 2 px line (180 ms), rows 30 ms apart, bars fill
  (200 ms); none under `REDUCED`. `stageText()` has a `gauges` branch.
- **`nix-status`:** a `gauges` plugin with one host: meters CPU, MEM, /,
  STORE, NET ↓, NET ↑; badges `gen`, `up`; a "Failed" list (user + system,
  tone `bad`, or "none" tone `ok`); `live: true`; `say` "All fine." / "One
  failed service: X." / "N failed services." (+ "Memory is high." at ≥ 90%);
  `os.statvfs` fallback when `disks` is missing; `cache_seconds: 4`; phrases,
  `reads`, no network unchanged; README: "Changed" once for folder copies,
  "Updated" for Nix ones; needs this Nixi version.
- **Budget:** refresh p95 < 400 ms on p620, < 800 ms on razer.

## Deviations

- **Step checks run from `tests/`** (2026-11-04, found at step 1): the test
  modules import each other (`test_plugin_stage` imports `test_speakable`), so
  `python3 -m unittest tests.test_x` from the repo root fails to import. Every
  step's check is `cd tests && python3 -m unittest test_x …`.

- **Step 3** (`b839fcf`, Sonnet coder): `disks` is `null` when both
  `statvfs` calls fail (an empty list would read as "no disks");
  `failed_system` is `null` when its query fails, like `failed`; the consent
  line is special-cased in the page's `reads` mapping.
- **Step 5** (`9fcdaab`): agy was assigned it; its run hung for 55 minutes
  with no edits ("tool exited 143" after the lead stopped it), so the Sonnet
  coder did it (handoff fallback). While the page is hidden or not shown, the
  refresh loop pauses rather than stops; a board restored from its tab stays
  as it was. The lead added the fixed dark palette for a light or
  low-contrast theme (`.fixed`, with a test) and a fresh 30 s before collapse
  once refreshing stops.
- **Step 6** (`0258806`, Sonnet coder): when both service queries fail, the
  Failed list says "unavailable" (tone `warn`) and he says "I couldn't check
  the services."; the plugin is version 2.0.0.
