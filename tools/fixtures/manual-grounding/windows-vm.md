# Windows VM

Omarchy can run Windows inside a VM on this machine.

## Using it

Start the Windows VM from the menu and wait for it to boot; the first boot
installs Windows, which takes a while. Once it is up, the VM opens in its own
window and you log in with the account you chose. Close the window to stop
the VM, and start it again from the same entry whenever you need Windows for
one program. The VM keeps its disk between runs, so anything you install
inside it stays there. Give it more memory in its settings if Windows feels
slow, and fewer CPU cores if the rest of the machine does.

## Sharing files

A shared folder is mounted inside the VM so files can move both ways.
