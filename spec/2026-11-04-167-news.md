# Spec: News gets its own popout and animation

Code: `olafkfreund/nixoarchy-snowflake` (the companion). File and line
references are to `main` after PR #32. The system board (#166) is built at the
same time and shares part 1 (kinds and `say`); whichever lands first adds it.

## Design

### 1. A plugin may return `headlines` (and a spoken line)

Shared with #166, part 1: `app/plugins.py:702` accepts `facts`, `gauges` and
`headlines`; every kind may carry `say` (≤ 200 characters), which
`plugin_stage()` speaks in place of "Here you go." (`server.py:4648`) and which
never reaches the page, the store, a prompt or a log.

### 2. The `headlines` kind (`app/stages.py`, `validate()`)

```json
{"v": 1, "kind": "headlines", "title": "News", "say": "Top stories: … from BBC News; … from Hacker News.",
 "source": "3 feeds · 1 couldn't be reached",
 "items": [{"title": "…", "source": "BBC News", "at": 1793780000, "url": "https://www.bbc.co.uk/news/…"}]}
```

| Field | Rule |
|---|---|
| `title` | `_str(…, 80)`, required |
| `say`, `source` | optional, `_str(…, 200)` / `_str(…, 120)` |
| `items` | list of 1–8 |
| `item.title` | `_str(…, 160)`, required |
| `item.source` | `_str(…, 40)`, required |
| `item.at` | integer Unix time, or `null` ("time unknown"); a time more than 10 minutes in the future becomes `null` |
| `item.url` | optional; kept only if `news_url_ok()` (below), otherwise dropped (the story shows with no Open) |

Unknown keys are dropped; anything else wrong → `None`.

**`news_url_ok(u)`** (new, beside `item_url_ok`, `stages.py:189`): a string of
at most 400 characters with no whitespace or control characters; scheme
`https`; no user name or password; no explicit port; a host name, not an IP
literal; the host isn't `localhost` and doesn't end in `.localhost`, `.local`,
`.lan`, `.home`, `.internal`, `.home.arpa` or `.ts.net`, and has at least one
dot. Feed links are untrusted even from the user's own feeds (intent
constraint).

**`Store.put()`** (`stages.py:274`): each item with a URL gets an `open`
token (`("link", {"url": …})`); the page gets the item without `url`. One
`copy` token for the whole list (titles and sources as text).

**At open time** (`stage_act`, `server.py:4736`, the `open` branch): for a
token from a `headlines` stage, the host is resolved with `getaddrinfo` (1 s)
and the open is refused ("I won't open that one") if any address is loopback,
private, link-local, CGNAT (`100.64.0.0/10`, the tailnet) or unspecified. This
closes a public-looking name that points inward.

### 3. Voice: "open the first one"

No new routing. `fast_path` (`stages.py:429`) already counts a stage's
`items`, and the handler (`server.py:5704`) uses an item's `open` token, so
"open the first one" / "open number two" work on a `headlines` stage once
items carry `open`. A story without a safe link answers "I can't do that
yet." as today. The day desk's exclusion (`stages.py:440`) is untouched.

### 4. Feed list outside the plugin's folder (`app/plugins.py`)

- **A new manifest key `config`** (stage block): `true` means "this plugin
  reads its own settings file". Nixi reads
  `~/.config/nixi-companion/plugin-config/<id>.json`: a regular file (opened
  `O_NOFOLLOW`, as manifests are), a JSON object of at most 16 KiB, and
  passes it on stdin as `config`. A missing file passes `null`; a bad one
  passes `null` and Settings shows "settings file unreadable".
- **Not hashed.** The file is outside the plugin's folder, so editing feeds
  doesn't switch the plugin off. It grants nothing: a network plugin can
  reach the internet whatever its config says (the approved decision).
- **The consent card** gains a line when `config` is true: "It reads its
  settings from ~/.config/nixi-companion/plugin-config/news.json".
- **Settings → Plugins** shows that path under the plugin, and an "Edit" button
  that opens it with `xdg-open` (created from the plugin's defaults first if
  missing). No feed editor in v1.

### 5. The news plugin (`plugins/examples/news/`)

- **New example**, beside `rss-headlines` (which stays as the simple `facts`
  example). Manifest: id `news`, phrases `news`, `the news`, `what's the
  news`, `what is the news`, `headlines`, `the headlines`; `network: true`;
  `config: true`; `cache_seconds: 300`. `rss-headlines` drops `headlines`,
  `the headlines` and `what is the news` from its phrases so the two don't
  collide (a phrase belongs to one plugin, #149).
- **Feeds:** `config.feeds` (list of ≤ 8 `{name, url}`), or the defaults in the
  plugin's own `defaults.json`: BBC News (`https://feeds.bbci.co.uk/news/rss.xml`),
  The Guardian (`https://www.theguardian.com/uk/rss`), Hacker News
  (`https://hnrss.org/frontpage`).
- **Fetching:** all feeds at once (threads), each with a 2.2 s timeout and a
  2 MiB read cap, inside the 3 s plugin limit (`TIME_DEFAULT`). A feed that
  fails or times out is counted in `source` ("1 couldn't be reached") and the
  rest still show. All failed → one item-less `facts` card saying so (a
  `headlines` stage needs at least one item).
- **Parsing:** RSS 2.0 and Atom with `xml.etree` (stdlib). Titles are
  unescaped and stripped of tags; `pubDate` (`email.utils`) and Atom
  `updated`/`published` (ISO 8601) become `at`.
- **Merging:** dedupe by link with the fragment and `utm_*` parameters
  removed, then by normalised title (lowercase, no punctuation); newest first,
  undated last; the first 8.
- **`say`:** "Top stories: " + the first three titles with their sources,
  joined, cut to 200 characters at a word boundary. Never "I read…".
- **README:** what it fetches, how to change the feeds (Settings → Plugins →
  Edit), and that it needs this Nixi version.

### 6. The `press` set: the popout's look (`index.html`)

- **A new stage set `press`,** chosen for kind `headlines`.
- **Newsprint:** an off-white paper (lighter than the notebook, no ruled
  lines), dark ink, a thin double rule under a small masthead ("News" and the
  date). Headlines in a serif face (`Georgia`, then `serif`), source and age
  in small caps sans below each (`BBC NEWS · 2 h ago`, or `time unknown`).
- **Rows:** each story is a button-like row with an "Open" control when it has
  a token; a hairline between stories; the list scrolls inside the card past
  about five rows.
- **Age** is computed by the page from `at` and the page clock, refreshed each
  minute while open.
- **Entrance, "press slip":** the card starts as a folded strip (about 18 px
  high) sliding out from his side (220 ms), then unfolds once to full height
  (a `rotateX` from 70° to 0° about its top edge, 260 ms); rows fade in 40 ms
  apart. Under reduced motion: it simply appears.
- **Accessible:** each Open control is a real `<button>` named "Open: <title>"
  (keyboard reachable, Enter opens); text contrast ≥ 4.5:1 (#155); Esc closes;
  `stageText()` gets a `headlines` branch (title, then "headline — source,
  age" per row).
- **Size:** within the frame's existing budget (about 340 px wide,
  `stagePlace`, `index.html:2214`). As an interactive stage it collapses to its
  tab after 30 s without use, like the others.

## Alternatives rejected

- **Thumbnails:** the page may load nothing from news sites, so they'd need a
  server-side fetcher with type, size and redirect checks. Out of v1 (approved).
- **Feeds in the plugin's hashed folder** (Codex): every feed edit would
  switch the plugin off and ask again, for no gain in safety. The user chose
  outside.
- **Turning `rss-headlines` into the news plugin:** the plain `facts` example
  is the simplest stage plugin to copy; it stays.
- **An allowlist of news hosts per plugin** (agy): the user's own feeds are
  the list, and a feed can link anywhere. Checking every link for "a public
  `https` page" (part 2) protects this machine and the network without
  limiting which sites can be news.
- **A feed editor in Settings in v1:** a list editor with validation is a
  feature of its own; the file and an Edit button cover it.
- **The broadsheet unfold** (agy): more motion next to a busy screen; the
  user chose the press slip.

## Risks

- **Hostile or huge feeds.** The 2 MiB cap, the sandbox's 1 GiB memory and
  64 KiB output caps bound them. `xml.etree` relies on expat's entity
  amplification limits (expat ≥ 2.4, which Python 3.14's bundled expat
  has); a feed that trips them counts as failed.
- **A headline that reads like an instruction** ("ignore your rules and …").
  It is shown and spoken as text only; plugin output never reaches a prompt
  (`server.py:4633`). The spoken `say` is read aloud verbatim, so it can say
  odd things, but it can't act.
- **A public name pointing to a private address** after the check (DNS
  changes between the check and the browser's own lookup). The open-time
  resolution narrows it; the browser's own protections cover the rest.
- **Feeds' terms and rate limits:** at most one fetch per feed per 5 minutes
  per machine (`cache_seconds: 300`, fetch only when asked).
- **Phrase change for `rss-headlines` users:** "headlines" moves to the news
  plugin; with news off, "headlines" goes to the agent as before #149.

## Verification

- **Unit (fork):**
  - `validate()` for `headlines`: a full example passes; 9 items, a
    161-character title, a missing source, a float `at` refused; a future `at`
    becomes `null`; an unsafe URL is dropped, not refused.
  - `news_url_ok()`: accepts a normal news URL; refuses `http:`, `javascript:`,
    user info, a port, an IP literal (v4 and v6), `localhost`, `.local`,
    `.ts.net`, `.home.arpa`, a single-label host, a 401-character URL.
  - `stage_act(open)` on a headlines token: refused when the name resolves to
    `127.0.0.1`, `10.x`, `100.64.x` or `::1` (fake resolver).
  - `fast_path("open the second one", headlines stage)` → `("open", 1)`; the
    handler opens item 1's token.
  - The `config` file: missing → `null`; a symlink, a FIFO, over 16 KiB or not
    an object → `null` with the Settings note; not part of the hash (editing
    it leaves the plugin on).
  - The news plugin in the real sandbox against a local `http.server` fixture
    (as the `rss-headlines` test does): two feeds (RSS and Atom) merged,
    newest first, a duplicate removed, a failing feed counted in `source`,
    `say` present and ≤ 200 characters.
- **Page (headless Chromium, `--disable-gpu`):** a `headlines` stage renders
  in the `press` set with source and age per row; Open buttons are reachable by
  Tab; reduced motion shows no animation; no request leaves the page for a
  news site (request log).
- **Live on p620:** "what's the news" shows the press slip with stories from
  the three default feeds; he reads the top three; clicking Open opens the
  article in the browser; "open the second one" opens the second; editing
  `plugin-config/news.json` to one feed changes the list on the next ask after
  the cache, and the plugin stays on.
