# Spec: Let each user choose Nixi's language (English, Norwegian, Polish)

Code: `olafkfreund/nixoarchy-snowflake` `main`. Line numbers are from the code
map of 2026-11-04.

## Design

### 0. The setting

- `language` ∈ `en | nb | pl` (Bokmål, Polish), settable via `/api/settings`
  and returned in `state_info`. The Whisper code for `nb` is `no`; the
  mapping is in one table, `LANGS`.
- **Default.** An existing `config.json` keeps its `language`. Today that is
  `"en"`, so English users see no change, whatever the machine's locale.
  Only a **first run** (no `config.json`) takes `nb` or `pl` from `$LANG`
  (`nb_NO`/`no_NO`/`nn_NO` → `nb`, `pl_PL` → `pl`), else `en`. This replaces
  the intent's "system locale" default, which two reviews showed could change
  an English user's Nixi.
- **Where:** Settings → Voice, a first row "Language" with the chips
  English · Norsk · Polski, and a status line (see 1).
- **No "Automatic" in v1.** Whisper's detection would pick a listening
  language while his voice, his replies and the shortcuts need one known
  language (both reviews). This changes the intent's recommended answer 4,
  and the user sees it before approving.

### 1. Listening: the model, the switch, the filters

- **Model** (`_load`, 2507–2516):
  - for `en`, `auto` stays `small.en` on CUDA and `base.en` on CPU;
  - for `nb` and `pl`, `auto` is `small` on CUDA and `base` on CPU
    (multilingual), and an explicit pick may be `tiny`, `base`, `small` or
    `medium`;
  - `whisper_model` validation (5521) accepts the multilingual names too. A
    `.en` model with `language ≠ en` is refused with "That model only knows
    English";
  - `run_whisper` passes `language=LANGS[lang].whisper`.
- **No deaf gap.** Switching language or model doesn't clear `_whisper`
  (today `reset_whisper()`, 2837, does so before the new model is ready):
  - a background thread loads the new model, with faster_whisper
    downloading it on first use;
  - the current model keeps transcribing until then;
  - when it is ready, it is swapped in atomically under `_whisper_lock`;
  - a failed download keeps the old model and shows the error.

  Settings shows "Downloading the Polish speech model (≈150 MB)…" and then
  "Ready". Until then, listening stays in the old language, and the status
  line says so.
- **Bounds** shown in Settings:
  - the multilingual `base` is about 150 MB on disk and `small` about 480 MB;
  - first-use download over the normal network;
  - on CPU, `base` should transcribe a short command in about the same time
    as `base.en` today. This is measured in the live check, and Settings
    suggests `small` only when a GPU is present.
- **Hints:** `stt_hint` (147–148) becomes per language. Each starts with the
  wake phrase in that language ("Hey Nixi" / "Hei Nixi" / "Hej Nixi") and
  the names (Claude, Nixi, NixOS…).
- **Filters:** the empty-result filter (2557) and `NOISE_WORDS` (2930) get
  per-language lists, with Whisper's known hallucinations:
  - pl: "Napisy stworzone przez społeczność Amara.org", "Dziękuję.";
  - nb: "Teksting av …", "Takk for meg.".

  English stays as today. The mic test hint (3175) names the chosen
  language.

### 2. The wake word and stop, in every language at once

- **`WAKE_RE`** (2931; quick.py 322 copies the name list) accepts the
  greetings of all three languages: `hey|hi|okay|ok|yo|oi|hei|hallo|hej|cześć`
  before the same name variants. The name itself is language-neutral. The
  wake transcription hint (3087) is the chosen language's wake phrase.
- **`STOP_RE`** (2857–2858) becomes the union of English and the chosen
  language, because people say "stop" in any language:
  - nb: `stopp|vent|stille|hysj|det holder|takk|ok takk`;
  - pl: `stop|czekaj|poczekaj|cicho|ciszej|wystarczy|dzięki|dziękuję`.

  Both are matched after the Unicode normalisation in section 3.

### 3. Normalising words without losing letters

- `stages.fast_path` (642) and `plugins.norm` (35–38) replace
  `re.sub(r"[^a-z0-9 ]", " ", s.lower())` with a Unicode-aware form: NFC,
  `casefold()`, then `re.sub(r"[^\w ]|_", " ", s)`. That keeps æ, ø, å, ą,
  ę, ł, ś, ż, ź, ć, ń and ó. Plugin phrases match exactly as before for
  ASCII text.
- `plugins.reserved()` checks every language's shortcut tables, so no plugin
  can claim "åpne den første" either.

### 4. Shortcuts in each language (English always works too)

- **`app/lang/<code>.json`** (new) holds each language's tables. `_ACT`,
  `_ORD` and `_PLAIN` are built from English plus the chosen language:
  - **verbs:**
    - run: kjør / uruchom;
    - copy: kopier / skopiuj, kopiuj;
    - open: åpne / otwórz;
    - play: spill, spill av / odtwórz, puść;
  - **ordinals 1–5:**
    - nb: første, andre, tredje, fjerde, femte;
    - pl, with gender forms: pierwszy/pierwszą/pierwsze, drugi/drugą/drugie,
      trzeci/trzecią/trzecie, czwarty/czwartą/czwarte, piąty/piątą/piąte;
    - digits stay;
  - **fillers:** den / det / nummer; numer;
  - **it/that:** den, det / to, ten, tę;
  - **nouns:** video, klipp / wideo, klip, film;
  - **plain:**
    - close: lukk / zamknij;
    - go back: gå tilbake / wróć;
    - show it: vis den / pokaż.
- **`quick.py`** (volume, timers, media, brightness and the rest: 451 lines of
  English regexes) is **not translated in v1**. Those phrases still work in
  English. In nb or pl they go to the agent, which can still do them (it has
  the same tools), only slower. A later issue can add translations.

### 5. His own lines, and his answers

- **Lines:** `app/lang/<code>.json` holds the fixed strings under keys. A
  `t(key, **slots)` helper replaces the literals:
  - the stage results (5809–5845: "Copied.", "Opening it.", "Playing it.",
    "Which one? Say the first, second or third.", "I couldn't do that.",
    "Done.", "Which one: … or …?");
  - `plugin_stage` (4673, 4689);
  - the pickers (4466, 4489, 4511);
  - `approval_say` (698) and `bridge_question` (692);
  - the quick replies stay English (section 4).

  Missing keys fall back to English.
- **Quips:** `app/quips.json` becomes per language (`quips.nb.json`,
  `quips.pl.json`), falling back to English per event.
- **Page-spoken lines** (index 2067, 2714, 2716, 3342) come from
  `state_info.lines`, so translation stays on the server.
- **The agent:** for `nb` and `pl`, the prompt note (4546) gains "Reply in
  Norwegian (Bokmål)." / "Reply in Polish.", spliced as the other clauses are
  (`note[:-3] + …`). `FOLLOW_NOTE` (2860) gets the same clause. The day
  summary stays English, because it is agent-facing.
- **Dates** in the page (2482) use the chosen locale (`nb-NO`, `pl-PL`,
  `en-GB`).
- **Translation quality:** the nb and pl strings are written for this change
  and flagged for a native check by the user before release (see
  verification). Nothing is machine-translated at run time.

### 6. Speaking: voices per language

- **Kokoro** v1.0 has no Norwegian or Polish voice. For `nb` and `pl`:
  - `auto` skips Kokoro;
  - an explicit `kokoro` shows "Kokoro has no Norwegian/Polish voice" (the
    #176 exact-choice rule).
- **piper:** for `nb` and `pl` the voice list is the piper voices that exist
  for the language, by name, rather than the English presets:
  - nb: `no_NO-talesyntese-medium`;
  - pl: `pl_PL-gosia-medium`, `pl_PL-darkman-medium`, `pl_PL-mc_speech-medium`.

  They download on first use through `fetch_voice` (3330), which already
  builds `pl_PL`/`no_NO` paths. The pitch presets (Cute, Deep) apply on top
  of the chosen voice. The exact voice names are checked against the piper
  voice index during the plan.
- **espeak:** `-v nb` / `-v pl`; the Robot preset becomes `nb+m3` / `pl+m3`.
- **ElevenLabs** (#176): its voice list shows each voice's languages, and the
  ones that speak the chosen language come first. The model
  `eleven_flash_v2_5` is multilingual.
- Changing language keeps the user's last voice per language
  (`voice_by_lang`), so switching back restores it.

### 7. Plugins

- Both callers (4675, 4767) pass `locale=LANGS[lang].locale` (`en`, `nb`,
  `pl`). It goes into the plugin cache key in `run_stage`, so a cached
  English result never answers a Polish ask.
- The news plugin's topic words (#174) stay English keys in v1. Users can add
  `"verden": "verdensnyheter"` themselves in `news.json`. Noted in its
  README.

## Alternatives rejected

- **"Automatic" language detection:** conflicts with one voice, one reply
  language and one set of shortcuts (both reviews). Revisit separately.
- **Translating `quick.py` now:** 22 replies and about 20 regexes with English
  number words and durations. A large, separate piece; the agent covers it
  meanwhile.
- **Machine translation at run time:** sends text out and gives unchecked
  wording. Static translations instead.
- **Translating the page labels now:** about 160 strings plus the JS ones.
  The intent puts them in a later step.
- **A multilingual model for English too:** slower and less accurate in
  English than the `.en` models, so English keeps them.

## Risks

- **Translation quality** of the nb and pl lines and shortcut words: needs a
  native check. Mitigated by the user's review before release and by
  English always still working.
- **CPU speed** of the multilingual `base` for nb and pl: measured live.
  Settings suggests `small` only on a GPU.
- **Polish inflection** beyond the listed forms (e.g. "otwórz drugiego"): it
  falls through to the agent, which still understands. A later improvement.
- **Whisper hallucinations** in nb and pl beyond the filtered phrases: seen
  in use, then added to the list.
- **Download size and time** on first switch: shown, and the old model keeps
  working.

## Revisions after review (binding; these override the sections above where they differ)

Codex (gpt-6-sol) and agy (model not reported) reviewed the draft. Each
finding was checked against the code. agy confirmed that all four piper
voice names exist upstream.

1. **Requested and active language are separate.**
   - `language` is what the user chose; `lang_active` is what Nixi uses now.
   - The switch completes only when both the new Whisper model and the new
     voice are ready. Then `lang_active` flips, in one step under a switch
     lock.
   - Until then, transcription, wake and stop words, the voice, the reply
     clause, shortcuts and lines all use `lang_active`, so the English model
     is never asked for Polish and he never goes mute.
   - Settings shows "Switching to Polski: downloading speech model / voice…",
     and he says once that he'll switch when ready.
2. **A safe model swap.**
   - A switch generation `sg` is bumped on every requested change; the loader
     thread carries its `sg`.
   - When the load finishes, it is installed only if `sg` is still current;
     a superseded load (en → pl → nb) is discarded.
   - The CPU fallback in `whisper()` and `run_whisper()` (2519, 2545) replaces
     `_whisper` only if `_whisper` is still the object it failed with (an
     identity check under `_whisper_lock`). A late failure on the old model
     never overwrites a new one.
3. **Translated verbs map to the existing actions.** A table maps each
   language's verb to `run|copy|open|play`, and `fast_path` returns the
   canonical action, so the callers (5826) are unchanged. `reserved()` uses
   the same tables.
4. **The reply language reaches every agent path:** the bridged prompt note
   (4546), `FOLLOW_NOTE` (2860), the non-bridged `run_claude`/`build_cmd`
   prompt, and `summarize_command`. One `lang_clause()` is used by all.
5. **Word fixes:**
   - **nb stop:** `stopp|vent|vær stille|hysj|det holder`, plus English. "Takk"
     and "ok takk" stop him as English "thanks" already does (parity, as
     reviewed).
   - **pl stop:** `stop|czekaj|poczekaj|cicho|ciszej|wystarczy|dzięki|dziękuję`,
     plus English.
   - **Wrappers:** `STOP_RE` also accepts a leading `hei nixi|hej nixi|cześć
     nixi`.
   - **nb shortcuts:** "it/that" is den|det; show it is "vis den|vis det";
     the cardinals en|to|tre|fire|fem.
   - **pl shortcuts:**
     - "it/that": to|ten|tę|tą|go;
     - ordinals with the `-ego` forms: pierwszego, drugiego, trzeciego,
       czwartego, piątego;
     - show it: "pokaż|pokaż to";
     - the cardinals jeden|dwa|trzy|cztery|pięć.
6. **The first-run locale** reads `LC_ALL`, then `LC_MESSAGES`, then `LANG`,
   ignoring the `.UTF-8` suffix.
7. **More fixed strings** found in review (in `server.py` and `speakable()`'s
   spoken replacements, e.g. "The rest is on screen.") join the `t()` table.
   `speakable()`'s path words ("your Downloads folder") are translated too.
8. **Intent changes for the user to confirm:**
   - the first-run-only locale default replaces "default to the system
     locale";
   - "Automatic" is dropped from v1.

   Both reviews agreed with the reasons.
9. **Added tests:**
   - transcribing during a download still passes `language="en"` to the old
     model;
   - en → pl → nb with pl finishing last installs nb;
   - a CPU fallback on the old model after a swap leaves the new model;
   - the speech voice stays on the old language while the new voice
     downloads;
   - `fast_path` returns canonical actions for every language;
   - `lang_clause` in all four agent paths;
   - the Polish `go`, `tą` and `-ego` forms;
   - "vær stille";
   - the `LC_ALL`/`LC_MESSAGES` precedence.
